# Locaz Auto Services : mises à jour

Ce dépôt contient seulement le logiciel Locaz Auto Services (LocazClim.exe), version par version, et la fiche `latest.json` de la dernière version.

Il ne contient aucune donnée : ni clients, ni factures, ni réglages. Elles restent sur le PC de chaque garage.

Le logiciel lit `latest.json` une fois par jour et propose la nouvelle version avec un bandeau vert. Rien ne s'installe sans un clic. Chaque fichier est signé : un fichier modifié est refusé.
